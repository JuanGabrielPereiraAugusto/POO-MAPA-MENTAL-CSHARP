# 🧠 Mapa Mental — Programação Orientada a Objetos com C#

Mapa mental com os principais conceitos de **Programação Orientada a Objetos (POO)**. Cada conceito tem uma **definição**, um **exemplo do cotidiano** e um **código em C#**.

📄 **Material completo:** [`mapa_mental_POO_CSharp.pdf`](mapa_mental_POO_CSharp.pdf)

## 🧩 Conceitos abordados

### 🟢 Blocos básicos

| # | Conceito | Resumo | No cotidiano |
|---|---|---|---|
| 1 | **Classes e objetos** | A classe é o molde; o objeto é a instância criada a partir dele | A planta de uma casa é a classe; cada casa construída é um objeto |
| 2 | **Atributos e propriedades** | Atributos guardam o estado; propriedades dão acesso com `get` e `set` | Nome, idade e altura de uma pessoa |
| 3 | **Métodos** | As ações que o objeto sabe executar | Um caixa eletrônico sabe sacar, depositar e consultar o saldo |
| 4 | **Construtores** | Inicializam o objeto no momento em que ele é criado | — |

### 🔴 Os quatro pilares da POO

| # | Pilar | Palavra-chave |
|---|---|---|
| 5 | **Encapsulamento** | `private` e `public` |
| 6 | **Herança** | Reuso de código |
| 7 | **Polimorfismo** | `virtual` e `override` |
| 8 | **Abstração** | O essencial e o contrato |

## 💻 Exemplo do material

```csharp
class Carro
{
    public string Modelo;
    public int Ano;
}

Carro meuCarro = new Carro();   // objeto
meuCarro.Modelo = "Onix";
meuCarro.Ano = 2022;
```
